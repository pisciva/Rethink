# Validation Engine

**Source:** PRD v2 Technical Blueprint; FR-C5-01–FR-C5-11.

Concept validation gates Transfer Problem on a valid Independent Retry pass and maps valid item results to the three Distributive Property learner states. Topic assessment is a separate five-item SPL Final Assessment with 3/5 passing, retry, and preserved attempt history. No transition may silently overwrite concept state with topic result.
