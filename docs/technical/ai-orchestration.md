# AI Orchestration

**Source:** PRD v2 Technical Blueprint; Design Requirements DR-06; FR-C3-06, FR-C3-08, FR-C4-09.

AI may interpret bounded reasoning evidence, conduct approved contextual follow-up, and provide Socratic learning assistance. Application orchestration controls scope, stage, allowed content, transitions, and fallback. Mathematical validators evaluate mathematical forms where applicable. Learner-state management consumes valid evidence and does not accept an unconstrained model judgment.

FR-C4-09 requires progressive hints, active reasoning, no final-answer leakage, no solving or grading Independent Retry/Transfer, and safe fallback for unavailable, uncertain, unsafe, or out-of-context responses. Current chat code is not verified against the complete C4-09 contract.
