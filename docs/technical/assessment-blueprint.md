# Assessment Blueprint

**Source:** PRD v2 DOCX Section 4.2.2; Detailed FR-C3-02 and FR-C5-09–FR-C5-10.

Primary diagnostic set: exactly Q1–Q10. Coverage spans target SPL performance, prerequisite application, conceptual reasoning, inverse/equality, grouping, signed-number reasoning, representation, and cross-form evidence. Multiple tags do not copy one response result to every concept.

Follow-up probes are separate from primary questions and require an information-gap objective, approved candidate or reviewed variant, non-leading wording, bounded budget, and termination rule.

SPL Final Assessment is a separate five-question topic assessment. It is not a replacement for the diagnostic and does not assign concept learner states.
