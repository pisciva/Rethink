# Reliability and Testing

**Source:** PRD v2 Technical Blueprint; Product Validation and Detailed Requirements.

Test normal, non-confirmed, uncertain, insufficient, invalid, interrupted, retry, transfer, duplicate, refresh/resume, AI failure, and unsupported-capability cases. Validate JSON/schema boundaries, mathematical equivalence, evidence provenance, safe AI fallback, state separation, and no answer leakage.

Repository tests cover the existing v2 single-concept journey. They do not verify complete Q1–Q10 screening, 43-FR acceptance, Socratic tutor behavior, or SPL Final Assessment.
