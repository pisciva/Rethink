# Logical Data Model

**Source:** PRD v2 Technical Blueprint; FR-C2, FR-C3, FR-C5, FR-X.

Logical records must preserve selected topic, concept tags, question/probe IDs and versions, raw responses, observations, supporting and contradicting evidence, coverage, priority, availability, diagnostic status, learning origin/completion, concept validation results, final-assessment attempts, scores, and retry history.

This is a logical contract, not a deployed schema. Current v2 journey state lacks Q1–Q10 per-concept evidence and SPL Final Assessment fields.
