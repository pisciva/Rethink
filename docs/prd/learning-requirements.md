# Guided Learning Requirements

**Source:** PRD v2 DOCX Section 4.3; Detailed Requirements FR-C4-01–FR-C4-09.

Learning is open after diagnosis. Learners can see prerequisite concepts, select available content, follow or ignore recommendation priority, and continue directly to SPL Final Assessment without completing every blocker. Availability must reflect implemented coverage.

The complete MVP package targets Distributive Property and follows: Visual Explanation → Worked Example → Partial Guided Practice. Partial practice requires active mathematical input. Lesson completion does not create a concept learner state.

FR-C4-09 adds contextual Socratic assistance during supported learning stages. The assistant uses the current concept and stage, approved content grounding, progressive hints, and safe fallback. It must preserve learner reasoning and must not reveal final answers or solve Independent Retry/Transfer items. See [AI orchestration](../technical/ai-orchestration.md).
