# Validation Requirements

**Source:** PRD v2 DOCX Section 4.3; Detailed Requirements FR-C5-01–FR-C5-11.

Concept validation is separate from topic assessment. Eligible confirmed recovery uses scaffold-free Independent Retry, then Transfer Problem only after retry passes. Valid results map to `Understood`, `Procedural Only`, or `Needs Reinforcement`; reinforcement returns to the existing package.

SPL Final Assessment is separate: exactly five curated questions per attempt, available after diagnosis without completing all blockers, pass at 3/5 or higher, Not Passed at 0–2/5, and retry after failure. Attempt history is preserved. Topic pass does not mark every prerequisite `Understood`; topic failure does not identify a causal blocker.

See [validation engine](../technical/validation-engine.md) and the complete matrix for canonical definitions.
