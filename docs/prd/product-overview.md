# Product Overview

**Source:** PRD v2 DOCX Sections 1.1–1.6.

ReThink is an AI-assisted mathematics conceptual recovery platform. It connects evidence-bounded diagnosis, curated guided learning, and independent validation. It is not a general mathematics tutor, unrestricted chatbot, full curriculum, or broad mastery assessor.

The learner starts from a mathematics catalog and selects a supported topic. The MVP diagnostic context is Sistem Persamaan Linear (SPL) under Algebra. Screening may cover several prerequisite concepts, but Distributive Property is the only concept with a complete recovery package in the MVP.

Core principles: evidence before inference; recovery depth over visible breadth; active reasoning over answer delivery; validation before understanding claims; bounded AI autonomy; represented concepts do not automatically activate capabilities.

See [MVP definition](mvp-definition.md) and [functional requirements](../implementation/FR-TRACEABILITY.md).
