# Diagnostic Flow

**Source:** PRD v2 Design Requirements; FR-C3-01–FR-C3-10.

Show exactly ten primary diagnostic questions. Do not leak correctness or diagnostic conclusions between primary items. Follow-up appears only for a named information gap, uses a separate probe ID, and remains bounded and non-leading.

Results show per-concept evidence status, coverage, learning priority, learning availability, and rationale. Use `Supported`, `Not Supported`, `Uncertain`, and `Insufficiently Assessed`; do not show arbitrary confidence percentages.
