# Socratic Tutor

**Source:** PRD v2 Design Requirements DR-06; FR-C4-09.

The tutor is contextual learning assistance, not an unrestricted chatbot. It receives current concept and stage, uses approved content, and provides progressive hints. It must not solve or grade Independent Retry or Transfer Problem items. Unavailable, unsafe, uncertain, or out-of-context responses use deterministic fallback.
