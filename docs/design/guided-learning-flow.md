# Guided Learning Flow

**Source:** PRD v2 Design Requirements; FR-C4-01–FR-C4-09.

The supported package runs Visual Explanation → Worked Example → Partial Guided Practice. Practice requires active mathematical input. Learners can select available packages and continue to the SPL Final Assessment without completing every blocker.

Contextual Socratic assistance uses progressive hints grounded in current concept and stage. It preserves reasoning responsibility, avoids final answers, and fails safely.
